ABOUT

A home for Gujarati Garba.

PlayGarba is a focused catalogue and player for Garba songs, artists, releases and longer Nonstop sets.

Listen now ↗ GitHub ↗

WHAT IT IS

Garba first. Everything else follows.

PlayGarba is not trying to be a general music service. The catalogue, player and visual system are built around Gujarati Garba.

CATALOGUE Organised around Garba.

Songs, artists, releases and longer sets stay distinct so the catalogue remains understandable.

PLAYER Built to stay out of the way.

Explore, favourites, queue and Nonstop sit around the music instead of competing with it.

ACCESS Browser first.

Use the live player in a browser or install it as a web app on supported devices.

GARBA STYLES

Six ways into the same catalogue.

Traditional, Dandiya, Devotional, Folk, Sanedo and Fusion are six starting points for browsing the same catalogue and player.

PLAYBACK

YouTube is the playback source.

Catalogue items are linked to verified YouTube routes. The video stays collapsed by default so the player remains centred on listening.

PRINCIPLES

Simple enough to disappear.

Stable controlsPrimary playback controls should not jump when titles or artwork change.
Responsive behaviourPhone, tablet and desktop layouts are treated as different interaction contexts.
Clear statesUnavailable playback, loading and offline states should be shown plainly.
Less decorationVisual detail should support the music, not turn every screen into a poster.

OPEN PROJECT

The repository is public.

The project includes the player, catalogue data, PWA implementation, validation scripts and project documentation.
