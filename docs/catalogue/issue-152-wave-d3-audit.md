## Tahukar 11

Amazon Music publishes `Tahukar 11` as a 13-track Kirtidan Gadhvi album dated 2024-10-01. The displayed split-track durations total 31:14.

The split provider calls track 1 `Chhand Thukar 11`, while the official chapter list shortens it to `Chhand`. This is retained as an exact route because the artist's own Tahukar 11 upload identifies it as the first chapter of the same 13-item programme. No neighbouring timestamp, provider ID or duration is inferred.

## Playback integrity
