# Issue #246 — Hemant Chauhan `Ghammar Vol: 3` YouTube migration audit

Canonical release: `hemant-ghammar-vol3-2008`

## Verified release identity

The canonical release is `Ghammar Vol: 3 (Nonstop Garba)` by Hemant Chauhan, released 2008-12-01 with 18 tracks and a 2008 Sur Sagar phonographic copyright. Provider track pages independently expose the same 18-song sequence and durations.

## YouTube audit result

No directly verifiable YouTube master, publisher-published chapter list, or set of exact 2008 Sur Sagar album-track watch URLs was recovered from indexed official evidence during this audit.

Searches were run against the exact album title, Sur Sagar / Soor Mandir / Sense World Music label terms, and the distinctive canonical track titles.

## Rejected candidates

A later `Rang Lagyo` release reuses many of the same song titles, and Kinjal Studio / Jhankar Music exposes related Hemant Chauhan videos. Those surfaces are not promoted because they are different releases and some durations/edits materially differ from the 2008 `Ghammar Vol: 3` album.

Examples include `Meladi Ramti Aave`, `Navratri Nav Norta`, `Patai Raja Garbadiyo`, and other overlapping titles. Same singer, composer, or title is not enough to prove recording identity.

## Playback decision

All 18 existing Amazon track URLs remain provenance only. They are non-executable under PlayGarba's YouTube-only runtime policy and are explicitly marked `youtubeMigrationStatus: unresolved`.

No YouTube ID, timestamp, chapter boundary, or recording equivalence is inferred. If an official 2008 Sur Sagar YouTube master or exact distributor track URLs become recoverable later, this evidence boundary can be reopened and upgraded safely.
