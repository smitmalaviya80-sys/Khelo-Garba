# Music and content sources

The repository ships with explicit placeholders only.

Before launch, every public track should have a verified source for:

- title
- artist / performers
- genre classification
- duration
- playable source and rights/permission to embed or stream it

Do not copy or host commercial audio without permission. If using an external provider, follow that provider's player, attribution, API and embedding requirements.

`audioUrl` is supported now for permitted direct audio. `youtubeId` is reserved in the schema for a later provider adapter and is not yet used for playback.
